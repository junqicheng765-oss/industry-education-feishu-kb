# 连接、权限与同步

本包提供规则与模板，不含飞书连接器、凭据、锁服务或调度。支持Markdown skill的Agent可加载；其他工具按其机制将SKILL.md作为说明并读取相对路径资源，不承诺所有工具自动发现。

## 接入与能力核验

首次接入先读团队配置及随包启动说明。已有团队指定应用时默认复用，不能把本机缺少profile解释为必须新建应用。区分应用未配置、个人OAuth未完成、应用API scope未生效及知识库内容权限不足；分别修复，不回退bot。管理员已明确允许共享应用凭据时，可引导成员通过终端隐藏输入App Secret并配置到指定profile；这不允许复制他人的个人访问/刷新令牌。已有同名配置用途不同时保留并报告冲突。应用配置、本人授权、只读验证、项目指令安装分别报告结果；需要人操作时一次给一个动作，完成后由Agent接续。

用[配置示例](../assets/workspace.example.yaml)建立团队配置。真实空间ID、文档入口、索引位置按团队规则保存，不混入公开分发包。凭据走宿主或团队秘密管理，不在对话里要求粘贴令牌。

| 能力 | 要核实什么 | 缺失时怎么做 |
|---|---|---|
| 节点读取 | space、node、实际对象类型和token | 明确目标后才同步，否则本地草稿 |
| 完整读取 | 分页、块结构、表格、附件/嵌入对象、可见范围 | 只改能完整理解的范围，其余补丁/待补 |
| 查重搜索 | 目标空间覆盖和权限遗漏 | 结合稳定ID/索引，不断言全局无重复 |
| 创建/局部写入 | 对象类型、格式保留、回读 | 无局部写能力交补丁，无写权限交待同步包 |
| 索引维护 | 实际app/table/field标识与授权 | 用页面清单并记录待补 |
| 并发保护 | 条件写、可靠锁或单写者机制实际可用 | 共享现行文档只交待应用补丁 |
| 权限核验 | 空间、父页面、文档、表格、应用与委托人范围 | 不扩大权限，无法核验的受限同步不做 |

优先已有且获授权的连接器/MCP/API，也可用获授权的浏览器流程。不虚构固定工具名，不把某个第三方插件设为全团队必需。调用API时查执行时官方文档与实际工具能力，不臆造端点、权限名、版本条件或限额。

知识库node标识与实际文档/表格对象标识不同，先确认对象类型再操作；展示URL不等于所有接口可用的ID。

## 权限与发布

本地整理、补丁和校验按用户任务做。用户明确委托目标空间维护，或可信团队授权覆盖对应动作时，直接执行，不逐条重新确认。技术写权限本身不等于业务授权。

用团队应用时，应用访问范围不能替代委托人的业务范围。工具不能证明边界时，仅维护已明确允许的资料。创建空间、设置分享、迁移、删除及关键承诺变更检查是否已有覆盖授权；没有时交具体计划，由有权人员补该动作授权，不为普通文本维护另设审批。

受限资料与索引单独配置。隐藏视图、隐藏列和提示词不是权限控制。权限验证覆盖普通成员、应用及分享/关联路径，不以管理员读写成功当隔离验证。

本skill不触发自动群发、定时检查或提醒；用户已授权通知时按其渠道约定执行，不能将投递成功说成已阅读。

## 没有连接

继续完成目录映射、正文、补丁与待同步清单，列明管理员需提供的非凭据入口：空间/根节点、索引、业务与治理负责人、授权范围、共享写入方式。不声称已创建空间或已同步。

## 官方能力依据（核对日期：2026-11-06）

以下为能力定位，不是本租户实测；执行时重新核对受版本、套餐和工具影响的部分。

- [知识库权限](https://www.feishu.cn/hc/zh-CN/articles/821998241087)：空间、页面、父级及管理员权限共同影响访问。
- [多维表格双向关联](https://www.feishu.cn/hc/zh-CN/articles/653027931590)：同一文件内跨数据表关联，不假设独立文件直接双向关联。
- [多维表格高级权限角色](https://www.feishu.cn/hc/zh-CN/articles/539823920318)：需核验角色、数据及分享路径的实际权限。
- [多维表格API常见问题](https://open.feishu.cn/document/docs/bitable-v1/faq?lang=zh-CN)：应用还需要内容授权，API scope不意味着可读写全部资料。
- [飞书开放平台](https://open.feishu.cn/document)：接口、对象类型、版本条件与限额以官方说明及实际工具为准，不宣称通用跨对象事务或原子锁已获验证。
