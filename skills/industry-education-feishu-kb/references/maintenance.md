# 内容、版本与多Agent维护规则

## 1. 核实依据

读取用户材料、项目当前状态和相关现行正文。原始事实、实际决定、已验证结果、建议、未知分别表达。文件标题、更新时间、截图、会议意见不是业务签认本身。冲突时比较对象、适用范围、时间、版本与有效决定，不用新草稿覆盖旧签认。

数字、数量、性能、期限、报价、合同和验收承诺回查原件，具体到文件版本/页码/章节或测试记录。网页记录标题、发布者、日期、链接和核验日期。动态政策、价格和平台能力查当前官方资料，不以旧摘要当新证据。

采购需求不证明能力已实现；本地Demo不证明生产集成；测试通过不等于院校签认。证据不足标明受影响段落与下一取证动作，不推测填满模板。

## 2. 元数据与状态

正文至少记录knowledge_id、entity_id、文档类型、归属路径、负责人、实际维护者、内容状态、版本、更新时间/时区、适用范围、可引用范围、保密级别、来源证据、确认依据、替代关系、复核日期或触发条件。未指定负责人写待指派，不捏造人名；未知字段如实标记。

| 内容状态 | 含义 |
|---|---|
| 草稿 | Agent整理稿或新内容，尚未有业务确认 |
| 待业务确认 | 需确认规则、能力或承诺，明确待确认点和影响 |
| 现行 | 有可追溯确认依据，或现行正文授权内不改变业务含义的修订 |
| 已替代 | 标明替代正文、版本和范围，保留旧证据与引用 |
| 已归档 | 不再作为现行使用，标明原因；不等于删除 |

Agent写完不能自升现行；实际确认已包含在用户请求或团队有效授权中则直接沿用，不重复询问。改拼写/补原始链接可保持现行；改变产品可售范围、价格、性能或验收承诺不能借编辑授权生效。部分段落待确认时单独标明，不让整篇现行标签为它背书。

产品能力另按功能项标记`已验证可交付/需配置或集成/需定制开发/规划中/待核验`，附证据、版本和环境，不与文档状态混用。

## 3. 新增与更新

1. 确定目标空间/父节点、对象、委托人、允许动作及来源；ID从配置或实际读取取得，不凭名字猜。
2. 先按knowledge_id/entity_id，再按同义名、来源与主题查重；读完整正文、元数据、相关引用和当前revision。搜索不全说明覆盖范围，无权限不等于不存在。
3. 已有正文就局部修订，保留他人段落、有效决定、附件和嵌入表格。跨类型材料拆解并互链。实质变更前保留可恢复旧正文或版本引用，备份权限不宽于原文。
4. 使用工具真实支持的局部更新能力。全篇替换仅限格式/对象可保留且范围允许时；无法保证图片、表格或嵌入对象保留，就交局部补丁或另存草稿。
5. 回读正文正确后更新索引、必要引用及变更记录。正文/索引/关联各记结果，失败部分进入待补清单。

现行产品正文可更新，但已报价、发送、签认的项目保留采用版本和快照。列出受影响方案或项目，不能自动改变其合同范围或改写已发送版本。

## 4. 并发、幂等与失败恢复

- 一次逻辑变更生成并保存一个`change_id`，重试沿用；用户改变内容/目标才新建ID。`knowledge_id`稳定，不能重试时重建。
- 写前保存基线revision；无revision时记录完整目标正文指纹与读取时间。执行前再次读，有变化就重新比较合并；同段冲突、业务决定冲突或无法完整读取则保存补丁，不覆盖他人内容。
- 工具明确支持条件更新时使用它。两次读取本身不能消除竞态；无条件更新时，需团队实际支持的单写者队列或可靠锁。普通多维表格一行“锁定”不天然原子。未验证可靠写入机制前，不自动写共享现行正文，改交待应用补丁给单一维护者执行。
- 新建前按knowledge_id/change_id查重。超时、断网或返回不明，先查已返回节点、稳定ID与变更记录，再决定重试。无法确定结果标未知，不盲目新建副本。
- 同一变更已完成且内容无变化，返回原结果，不新造版本/日志。正文已建但索引失败，复用原节点补索引。
- 临时错误按工具要求退避，同一逻辑动作最多自动重试2次，仍失败/不明保存状态及补丁。无权限、参数错误不循环重试，不换身份绕过。
- 正文、索引、关联不是一个原子事务；恢复仅补未完成部分。有他人后续修改时，不整篇回滚，只撤销可明确属于本次的改动，否则交冲突补丁。

以上为执行规则，不表示本包已部署锁、队列或同步服务。

## 5. 版本、复核与归档

沿用已有版本规则。无约定时草稿从v0.1递增，第一次实际获确认形成v1.0；不改核心含义的补充升小版本，范围或关键业务规则变化升大版本。内容版本与平台revision分开。仅改格式不能伪造新业务确认。

实质变更记旧/新版本、原因、范围、来源、确认依据及维护者。复核按产品版本更新、报价有效期、项目里程碑、政策更新或纠错等触发，固定频率由团队约定，不承诺自动每周运行。

归档先标状态、原因、日期及替代链接。需移动到99、跨空间迁移、改权限或删除时查已有授权；检查引用、回链及权限影响。

## 6. 无连接时的待同步包

在用户工作目录按任务建文件夹：`entries/`放模板正文；`changes.md`记录change_id、knowledge_id、目标、拟改章节、来源、是否读过远端基线、执行结果与恢复动作。敏感内容只写用户允许的受限位置，不进入普通共享目录。

有远端基线附最小补丁与受限恢复引用；无基线明确为候选新增/合并稿。恢复后重新读现行内容、权限与查重，再应用，不能用本地生成日期覆盖远端新变化。

报告区分内容状态和执行状态，给入口、回读证据、未完成部分及责任角色。文件保存、接口成功、回读验证和业务确认分别报告。
